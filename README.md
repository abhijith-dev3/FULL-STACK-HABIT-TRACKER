# 📊 Full Stack Habit Tracker

A full-stack web application to track daily habits, built using **MERN stack (MongoDB, Express, React, Node.js)** with authentication and protected routes.

---

## 🌍 Live Links

- 🔵 Frontend: https://full-stack-habit-tracker.vercel.app  
- 🟢 Backend API: https://full-stack-habit-tracker-fd2t.onrender.com  

---

## ⚙️ Tech Stack

**Frontend:**
- React (Vite)
- Axios
- React Router

**Backend:**
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- CORS

---

## 🔐 Features

- User Signup & Login
- JWT Authentication
- Protected Routes
- Create / Read / Delete Habits
- Daily Habit Tracking
- REST API Integration
- Full-stack deployment
