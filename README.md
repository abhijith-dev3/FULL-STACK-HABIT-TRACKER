# 📊 Full Stack Habit Tracker

A full-stack web application to track daily habits, built using **MERN stack (MongoDB, Express, React, Node.js)** with authentication and protected routes.

---

## 🚀 Live Demo

- 🌐 Frontend (Vercel): https://full-stack-habit-tracker.vercel.app/ 
- ⚙️ Backend (Render): https://full-stack-habit-tracker-6c9x.onrender.com

---

## ⚙️ Tech Stack

**Frontend:**
- React (Vite)
- Axios
- React Router

**Backend:**
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- CORS

---

## 🔐 Features

- User Signup & Login
- JWT Authentication
- Protected Routes
- Create / Read / Delete Habits
- Daily Habit Tracking
- REST API Integration
- Full-stack deployment
